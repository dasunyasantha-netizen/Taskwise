## Summary

Add nullable `Task.blockedReason String?` so BLOCKED tasks can store an
optional human-readable reason. Forward migration is additive
(`ADD COLUMN IF NOT EXISTS`); rollback drops the column
(`DROP COLUMN IF EXISTS`). Dry-run (migrate deploy → verify → rollback →
re-apply forward) ran on **taskwise_test** only via peer auth / unix socket;
never pointed at production.
